# SIGNAL DESK

암호화폐 매수/매도 시그널 대시보드. **거래소 7곳**의 시세로 **16개 지표**와 종목별 탐욕지수를 계산해
−100~+100 점수와 5단계 등급, **거래소 합의도**, **실시간 수급**, **코인 뉴스·시장 심리**를
함께 보여준다. 감시 종목은 업비트 KRW 마켓 287종목에서 직접 고른다(최대 6종목).

| 국내 | 해외 |
|---|---|
| 업비트(KRW) · 빗썸(KRW) · 코인원(KRW, 시세만) | 바이낸스(USDT) · Bybit(USDT) · 코인베이스(USD) · 크라켄(USD) |

빌드 도구도 의존성도 없다. 정적 파일을 그대로 열면 동작한다.

## 실행

```bash
python3 serve.py 8000
# http://localhost:8000
```

`serve.py` 는 정적 파일 제공과 **뉴스 중계**를 함께 한다(파이썬 표준 라이브러리만, 의존성 없음).
뉴스 RSS 는 어느 매체도 CORS 를 열어주지 않아 브라우저가 직접 읽을 수 없어서다.

`python3 -m http.server` 로 띄워도 동작한다. 그 경우 시장 심리 카테고리만 빠지고 지표·수급은
그대로 계산된다.

백그라운드 실행·종료, SSH 터널, systemd 등록, 문제 해결은
[`docs/서버-구동.md`](docs/서버-구동.md)에 정리해 두었다.

일곱 곳 중 여섯 곳이 공개 API 에 CORS 를 개방하므로 브라우저에서 직접 호출한다. 서버도,
API 키도, 회원가입도 필요 없다. 인증이 필요한 주문 API 는 쓰지 않는다.

**코인원만 예외다.** 공개 API 가 CORS 헤더를 주지 않아 브라우저에서 캔들을 받을 수 없다.
WebSocket 은 제약이 없으므로 시세만 표시하고 지표 판정에서는 제외한다(화면에 사유를 적는다).

원격 서버에서 띄웠다면 로컬로 터널을 뚫어 접속한다.

```bash
ssh -N -L 8000:localhost:8000 <사용자>@<서버>
```

## 테스트

```bash
node --test test/
```

지표 계산, 시그널 판정, 거래소 집계, 어댑터 파싱을 검증한다. 어댑터 테스트는 실제 응답에서
잡아온 고정 픽스처를 쓰므로 네트워크 없이도 돌아가고, 연결이 되면 실응답 스모크까지 함께 돈다.

WebSocket 을 실제로 확인하려면:

```bash
node --experimental-websocket <스크립트>   # Node 20 은 플래그로 전역 WebSocket 을 제공한다
```

## 구조

| 파일 | 역할 |
|---|---|
| `js/config.js` | 종목·봉 주기·가중치·등급 기준의 단일 원본 |
| `js/indicators.js` | SMA/EMA/RSI/MACD/볼린저/거래량비/ADX·DMI/스토캐스틱/ATR/OBV/다이버전스 — 순수 함수 |
| `js/signal.js` | 지표 → 판정 → 카테고리 → 봉 주기 점수, ADX 동적 가중 — 순수 함수 |
| `js/aggregate.js` | 거래소 점수 → 합의도 · 수급 합산 · USDT 기준 괴리 — 순수 함수 |
| `js/flow.js` | 호가 불균형·체결강도 (업비트 호가·체결 스트림) |
| `js/news.js` | 뉴스 키워드 감성·공포탐욕·커뮤니티 투표·검색 관심도 |
| `js/greed.js` | 종목별 탐욕지수 (표시 전용) |
| `serve.py` | 정적 파일 + 뉴스 RSS·심리 지표 중계 (5분 캐싱) |
| `js/markets.js` | 업비트 종목 목록·검색·선택 저장 |
| `js/transitions.js` | 등급 전환 기록 |
| `js/exchanges/*` | 거래소 어댑터 7종과 레지스트리. `upbit-style.js` 는 업비트·빗썸 공용 |
| `js/realtime.js` | WebSocket 연결·재연결·거래소별 폴링 강등 |
| `js/chart.js` | SVG 캔들차트 + RSI 서브차트 (외부 라이브러리 없음) |
| `js/format.js` | 시세·비율·시각 표기 |
| `js/app.js` | 상태, 렌더 스케줄, DOM 조립 |

`indicators.js`·`signal.js`·`aggregate.js` 는 브라우저 API 에 의존하지 않는다. 시그널이
옳다는 보증이 테스트뿐이므로, 계산을 DOM 과 네트워크에서 떼어내는 것이 이 구조의 핵심이다.
거래소를 하나에서 일곱으로 늘리는 동안 `indicators.js` 와 `signal.js` 는 한 줄도 바뀌지 않았다.

## 지표 체계

지표 12개를 5개 카테고리로 묶는다. **카테고리 안에서는 단순 평균, 카테고리 사이에만 가중**을
두어 서로 닮은 지표가 같은 근거를 여러 번 세지 않게 한다.

| 카테고리 | 지표 | 가중 |
|---|---|---|
| 추세 | MA20/60 · MACD · ADX/DMI | 1.2 |
| 모멘텀 | RSI · 스토캐스틱 · RSI 다이버전스 | 1.0 |
| 변동성 | 볼린저 %B · ATR 백분위 | 0.8 |
| 거래량 | 거래량비 · OBV 방향 | 0.7 |
| 실시간 수급 | 호가 불균형 · 체결강도 | 1.0 |
| 시장 심리 | 공포탐욕지수 · 뉴스 심리 · 커뮤니티 투표 · 검색 관심도 | 0.6 |

**ADX 가 국면을 판별해 가중을 자동 조정한다.** 추세장(ADX ≥ 25)에서는 추세 ×1.5 · 모멘텀
×0.7, 횡보장(ADX < 20)에서는 추세 ×0.6 · 모멘텀 ×1.3. 추세장의 과매수는 '비싸다'가 아니라
'계속 오른다'는 뜻이라 매도 신호로 세면 추세 신호가 상쇄돼 버린다. 같은 지표값(추세 +70,
모멘텀 −80)이 국면에 따라 `중립(1.8)` → `매수(28)` → `매도(−26.5)` 로 갈리는 것을 테스트로
고정했다.

**실시간 수급**과 **시장 심리**는 봉 주기가 없는 지표다. 캔들 기반 지표는 본질적으로 지연
지표라 '지금 사도 되나'에 답하지 못한다. 수급은 업비트 호가 30단계와 체결 방향에서 직접
계산한다. 캔들 합의 : 수급 : 심리를 **3.7 : 1.0 : 0.6** 으로 합쳐 수급 18.9%, 심리 11.3% 를
차지한다.

## 뉴스를 어떻게 반영하나

뉴스 5개 매체(TokenPost·블록미디어·CoinDesk·Cointelegraph·Decrypt)의 헤드라인을 한글·영문
키워드 사전으로 채점한다. 종목이 언급된 기사는 시장 전체 기사보다 무겁게(1.0 vs 0.4), 오래된
기사는 가볍게 반영한다.

**키워드 방식의 한계를 감추지 않는다.** 브라우저에서 언어 모델을 돌릴 수 없어 사전 방식이고,
사전은 문맥을 오해한다. 그래서 세 가지로 완화했다.

1. 긴 표현을 먼저 검사한다 — `상장폐지`(−3)와 `상장`(+3)이 함께 걸려 상쇄되는 것을 막는다.
   `숏 청산`(+2)도 일반 `청산`(−2)보다 먼저 걸려야 숏스퀴즈를 하락으로 오독하지 않는다.
2. 부정어 뒤 해소 표현(`해소·완화·끝났·종료·탈출`)이 오면 무효로 본다 — `약세장 끝났다` 는
   긍정 기사다.
3. **걸린 키워드와 헤드라인을 그대로 보여준다.** 위 두 오류는 화면에 띄워 둔 덕에 잡혔다.
   가중도 가장 낮게(0.6) 두었다. 이 값을 신뢰도 높은 신호로 취급하면 안 된다.

## 종목별 탐욕지수

alternative.me 의 공포탐욕지수는 BTC 기준 시장 전체 값 하나뿐이라 모든 종목에 같은 숫자가
찍힌다. 그래서 같은 산출 방식으로 종목별 지수를 만들어 나란히 보여준다 — `시장 65 탐욕 ·
XRP 37 공포` 처럼 어긋남이 드러나는 것이 요점이다.

성분은 모멘텀 35%(RSI) · 변동성 25%(ATR 백분위, **역방향**) · 거래량 20% · 소셜 12%(투표) ·
관심도 8%(검색 상위)다. 변동성은 원 지수도 '이례적 변동성은 공포' 로 보므로 뒤집어 넣는다.

**점수에는 반영하지 않는다.** 재료가 이미 시그널 점수에 들어간 지표들이라 다시 넣으면 같은
정보를 두 번 세게 된다.

**공포탐욕지수는 역추세로만 쓴다.** 이 지수는 가격 모멘텀 25% + 변동성 25% 로 구성돼 다른
지표와 성분이 절반 겹친다. 그대로 더하면 이중 계산이고, 역발상으로 쓰면 새 정보가 된다.

## 화면 조작

| 요소 | 동작 |
|---|---|
| `종목 N/6` | 종목 선택 패널 — 검색해 추가, 칩·카드 × 로 제거, 기본값 복원 |
| `일시정지` | WebSocket 7본을 끊고 캔들 조회를 멈춘다. 값은 그대로 남는다 |
| 카드 클릭 | 차트·격자·상세·뉴스가 그 종목으로 |
| 차트 `거래소`·`주기`·`보조` 탭 | 거래소 6곳 · 봉 주기 3개 · 보조 지표(RSI/MACD/스토캐스틱) |
| 거래소 합의 표의 행 | 눌러서 상세를 볼 거래소 선택 |
| 차트 호버 | 십자선 + 해당 봉의 시·고·저·종·거래량 |

탭을 다른 곳으로 옮기면 캔들 조회가 자동으로 멈추고, 돌아오면 즉시 한 번 받는다.
페이지를 떠날 때 소켓을 정리한다.

## 읽는 방법

**시그널 점수**는 지표를 낸 거래소 점수의 등가중 평균이고, **합의도**는 거래소들이 서로 같은
방향을 가리키는 정도다. 둘은 다른 것을 재므로 나란히 놓았다 — `점수 +18 중립 · 합의 4/6
매수 우세` 같은 상태가 그대로 읽힌다. 여러 거래소가 동시에 가리키는 시그널은 한 곳의 수급으로
생긴 노이즈가 아니다.

카드의 게이지는 시그널 점수와 거래소들을 **하나의 축**에 얹는다. 마커가 모여 있으면 합의,
흩어져 있으면 이견이다.

카드의 `시그널 +18점 · 캔들 −1 · 수급 +90` 은 산술을 드러낸 것이다. 합의 배지가
`6/6 완전 일치 · 캔들 중립` 인데 점수가 매수인 경우가 있는데, 합의는 거래소들의 캔들 판정이고
수급은 업비트 단독 신호라 거래소 간 합의에 참여할 수 없기 때문이다.

**전환 기록**은 등급이 바뀐 순간만 남긴다. 순간 값만 보면 방금 매수로 돌아섰는지 원래
매수였는지 구분할 수 없다. 각 기록에 그때의 주요 근거 지표가 함께 붙는다.

거래소마다 일봉 시작 시각이 다르다 — 업비트는 09:00 KST, 빗썸은 00:00 KST 기준이라 같은
종목의 일봉 지표가 서로 다를 수 있다. 버그가 아니라 시장 데이터의 정당한 차이다.

**USDT 기준 괴리**는 흔히 말하는 김치 프리미엄과 다른 값이다. 은행 환율 대신 업비트
KRW-USDT 시장가를 쓰므로 USDT 자체의 프리미엄이 빠지고, 거래소 사이의 순수 가격 차이만
남는다(평소 0% 근처). 시그널 점수에는 반영하지 않는다.

지표별 구간과 가중치, 설계 근거, 구현 중 잡은 결함 기록은
[`docs/개발지시서.md`](docs/개발지시서.md)에 있다.

## 고지

공개 시장 데이터에 기술적 지표를 적용한 계산 결과다. 투자 자문이 아니며 미래 가격을
예측하지 않는다.
